# C Lab Assessment

A modular C programming project containing two tasks:
1. **Triangle Checker**: Inputs two angles, calculates the third, and determines if it is a right-angled triangle.
2. **Palindrome Checker**: Reverses an integer's digits to check if it reads the same forward and backward.

## How to Compile & Run
```bash
gcc main.c triangle_checker.c palindrome.c -o lab_assessment
./lab_assessment
